# [cutiepro](https://github.com/cutiepro/cutiepro)

## _a comfy theme to keep you soft and warm._

a dark pastel theme emphasizing warm colors and cute vibes, while being as
readable and elegant as possible.

available for a growing number of applications! see all the
editors/terminals/tools/+more that cutiepro has been ported to
[below](#supported-apps) ♡
